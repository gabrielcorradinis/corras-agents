# Registro de decisões do time

Cada decisão que o time tomou sozinho durante o modo autônomo, no lugar de perguntar ao humano. Ele lê na volta para aprovar ou pedir troca. A mais nova embaixo.

Formato de cada entrada:

```
### AAAA-MM-DD · <assunto curto>
- Quem decidiu: sessão principal | refinador-tecnico | arquiteto | implementador | ...
- Spec/tarefa: specs/<nome>.md, Tarefa N
- Pergunta: o que precisava ser decidido
- Escolha: o que foi feito
- Alternativas: o que mais dava para fazer
- Por quê: em uma ou duas frases
- Desfazer: fácil | trabalhoso | difícil (e o que custaria)
- Revisar: sim | não (sim quando o humano provavelmente teria opinião)
```
